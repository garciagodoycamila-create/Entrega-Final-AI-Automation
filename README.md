# Entrega-Final-AI-Automation
Proyecto final Coderhouse - Automatización de atención al cliente con n8n, Gemini, Gmail y Notion.
## Tecnologías utilizadas

- n8n
- Google Gemini
- Gmail
- Notion

## Descripción
Este proyecto automatiza la gestión de consultas recibidas por correo electrónico para la marca KHAM.
Las consultas provenientes de Tiendanube son registradas en Notion, analizadas por Gemini y almacenadas junto con una propuesta de respuesta para su revisión (Human in the Loop). Los correos que llegan por otras consultas son derivados a una segunda base de datos y procesados por un agente que arma un resumen del mail y propone una respuesta.
